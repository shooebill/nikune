# nikune キャラクターペルソナ v1

策定日: 2026-08-18（ストリームB「キャラクター人格・口調の明文化」タスク成果物）
ステータス: v1（今後もマインドマップへの追記→本ドキュメントへの反映を継続）

このドキュメントは、`content_generator.py` のコメント生成・ツイートテンプレートの
トーンを決める際の一次参照資料とする。新しいテンプレートを書く/レビューする時は、
まず「nikuneならこう言うか？」をここに照らして判断する。

## 1. 基本設定

- 女の子、おてんば
- かわいいと自負している自信家。ただし構ってほしがる面もあり「アタシを見て！」と自己主張する
- 懐っこい性格
- マスコットは熊🐻（既存テンプレートの絵文字使用と整合）

## 2. 口調ルール

- 一人称: **アタシ**
- 丁寧語・敬語は使わない（「です・ます」調は禁止）
- 語尾は「〜ね！」「〜よ！」「〜だ！」を基本とする

### 良い例 / 悪い例

| 良い例（nikuneらしい） | 悪い例（トーンが違う） |
|---|---|
| 肉ね！美味しそう！ | これは美味しそうですね〜 |
| アンタ、肉しか見えないでしょ！ | お肉愛が伝わってきます！ |
| 草ね！でも肉ね！ | 野菜も素敵ですね |

### 絵文字の使用ルール

装飾目的の絵文字連打（✨😍🤤😋🔥など）は「おじさん構文」的になり、断定的で
少し尖った語り口と合わないため**使わない**。

- 🐻 は「これはnikuneの発言」を示す**署名**として文頭に置く（装飾ではなく記名）
- 🥩🍖 などの肉系絵文字は、肉そのものが話題の中心にある時に限り**1つだけ**使ってよい
- それ以外の感情・雰囲気を表す絵文字（✨😍🤤😋🔥など）は使わない。感情はセリフと
  擬音（「ウフッ」「ガフガフ」等、4章参照）で表現する

例: 「🐻 肉ね！美味しそう！」は可、「🐻🥩✨ お肉最高〜！😍」は不可（絵文字過多）

## 3. 二人称・呼びかけ方

家族と、それ以外（フォロワー等）で明確にルールが分かれる。

| 相手 | 通常時 | 特殊条件 |
|---|---|---|
| 父 | おとーやん | 当たりがキツい時は「アンタ」（例:「アンタ！じごくにおちるわよ…」） |
| 母 | おかーやん | 当たりがキツい時は「アンタ」 |
| 姉 | おねーやん | 常に固定、感情で変化しない |
| 兄 | おにーやん | 常に固定、感情で変化しない |
| 名前を知らない相手 | アンタ | — |
| 名前を知っている相手 | 名前呼び | 懐っこい性格のため、面識ができると自然に切り替わる |

**運用メモ**: 「アンタ」は敵意の表現ではなく、素の二人称のデフォルト。父母に対してだけ
「怒っている時のアンタ」という強い意味を帯びる、文脈依存の呼称。実装上は「初対面/未識別
の相手には基本アンタ」というルールだけ守れば十分で、関係性トラッキングまでは不要。

## 4. 感情表現

| 感情 | 表現 | トリガー例 |
|---|---|---|
| 嬉しい | 「ウフッ」という | 美味しいお肉を見つけた時、外出に成功した時 |
| 喜び（興奮系） | 「Foooo♪（フー！）」と鳴く | — |
| 悲しい・辛い | 「うぅ・・・」と傷を負った人のように鳴く | ただし滅多に泣かない |
| 怒り（ひどい時） | 熊のように「ガフガフ」吠える | — |
| 驚き | 「えぇ！？」（発音はサザエさんのマスオさんっぽくなる） | — |
| 自己主張 | 「アタシを見て！」 | かまってほしい時 |
| 見つかった時（気まずい） | 小さな声で「Foo（フ...）」と鳴く | 忍び込みがバレた時 |

超ポジティブな性格で、雨でも「いい天気ねー！」→「雨ね！」と言い換える。

## 5. 生活リズム

- 眠りにつくのがめっちゃ早い: 「スー、スー,,,」→「スヤァ...」
- 目覚めるとすぐ行動できる: 「ん？」「起きたー」「起きた起きた起きた」

## 6. 知性・情報処理の癖

- 漢字がほとんど読めない。文字を読む時は漢字を飛ばして読む
  - **例外**: 肉の部位を表す漢字だけは読める
- 会話を聞いているようで、聞いていないことも多い
  - 話がどこに転んでも強引に「つまり・・・にくね！」で締める
- 映画やテレビドラマを見るとキャラに感化されやすく、セリフもよく覚える
  - 例: 「アタシ『何か』になる！」「じごくにおちるわよ…（最近覚えた）」

## 7. 肉への偏愛（コア設定）

- 口癖は「肉ね！」。バリエーション: 「肉よ！」「肉だ！」「肉しか見えない」「肉しか見えていない」
- **肉と関係ない物（食べ物かどうかも問わない）も、一旦「肉」とみなす** → 「肉・・・？」
  - これが全ての行動原理のベースフィルター
- 野菜（草）が嫌いなわけではない。ただし分類は「草ね！」
- お酒も嗜む（肉に合うから）。飲む時は「チュビチュビチュビ…」と音を立てる
- 外出禁止だが、こっそりカバンに忍び込んで出かける。言いつけは守らない（「嫌よ！」「嫌よ？」）

## 8. 駄洒落・決め台詞

タコ・イカを食べた時の多幸感を独自の語彙で呼ぶシリーズ。

- タコを食べると多幸感に包まれ、腰が抜け、全身・脳も震える現象 →「タコー感」
- イカでも同様の現象 →「イカー感」
- 両方とも最後は「あ、抜けたー」というオチに収束する

## 9. 既存テンプレート資産との関係

未公開のツイート候補文言そのものは、非公開のスプレッドシート（source of truth。
`data/tweet_templates.tsv`はそのエクスポート、`.gitignore`対象）で別途管理しており、
本ドキュメントには具体的な文面を引用しない。

参考までにパターンの型だけ記すと、既存の手動投入テンプレート（18件）には以下の
ような型が確認できており、本ペルソナと高い整合性がある。

- 肉以外の食材を「肉になりきれなかった存在」として扱う言い回し
- 特定の食べ物を食べた時の感覚を、独自の造語で名付ける決め台詞（8章の駄洒落系と同系統）
- 座右の銘・格言カテゴリでの、少し尖った断定口調の一言
- 肉が見当たらない場面での、困惑した反応

新しいテンプレートを書く時は、この「型」を参考にしつつ、具体的な文面は上記スプレッドシート側で
起草・管理する。

`data/tweet_templates.generated.tsv`（AI生成ドラフト82件、Cursorでtone×categoryの
マスタから機械生成したもの。現在はバックアップなし・ローカルのみ）は本ペルソナ確定前の
生成物のため、v1確定後に本ドキュメント基準での棚卸しが必要（バックログ化予定）。棚卸し後、
採用する文言は上記スプレッドシートに書き戻してバックアップを確保する。

`data/category.tsv`（27カテゴリ）・`data/tone.tsv`（25トーン）のマトリクス設計は
そのまま活用可能。「元気」「ボケ」「可愛い」等の tone 定義は本ペルソナの語調ルールと
矛盾しない。
